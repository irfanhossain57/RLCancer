# SC-RLOT: Reinforcement Learning for AML Drug Resistance Prediction

> **A Reinforcement Learning Framework for Adaptive Sequential Treatment Optimization Using Single-Cell Multi-Omics in AML Drug Resistance**



---

## Overview

SC-RLOT is a complete deep learning pipeline for **AML (Acute Myeloid Leukaemia) drug resistance prediction and treatment optimisation**. It uses Reinforcement Learning to learn the optimal drug sequence for suppressing resistant cancer cell subpopulations.

**4-stage pipeline:**

```
scRNA-seq (GSE220112 — 15,000 AML cells: DMSO=sensitive, Wee1i=resistant)
        │
        ▼
[1] Custom PyTorch VAE    500 HVGs → 32-dim latent space (MSE + KL loss)
        │
        ▼
[2] GATv2 Classifier      Cell-cell k-NN graph → resistance probability per cell
        │
        ▼
[3] PPO RL Agent          Subclone proportion state (OBS_DIM=9) → optimal drug
        │
        ▼
[4] SHAP + Beat AML       Gene-level explanations + 2-cohort clinical validation
```

Trained on Kaggle T4 GPU. Deployed as Docker + Streamlit. Two MLflow experiments. Clinically validated against Beat AML 2018 (Spearman r) and Beat AML 2022 (Kaplan-Meier log-rank).

## File Roles — Purpose of Every File

| File | Role | When to Run |
|---|---|---|
| `configs/config.yaml` | **Single source of truth** — every script opens it with `yaml.safe_load()` on startup; zero hardcoded values anywhere | Never run directly |
| `src/data_download.py` | **One-time setup** — downloads PBMC 3k (37 MB), GDSC2, GDSC1, GSE220112 (~420 MB) | **Once only** |
| `src/train.py` | **Full 7-step pipeline × 2 experiments** — Exp1 (baseline, `_exp1` suffix) then Exp2 (tuned, no suffix); Step 6 merges GDSC1+GDSC2 → `gdsc_merged_ic50.csv` | For local retraining; Kaggle is primary |
| `src/rl_env.py` | `CancerDrugEnv` — subclone state zero-padded to `OBS_DIM=9`; Darwinian regrowth; Venetoclax ×0.7 + Quizartinib ×0.6 resistance penalties | Imported by train.py + app.py |
| `src/evaluate.py` | Auto-finds best model (`no-suffix → _exp2 → _exp1` fallback); generates confusion matrix + SHAP chart + PPO comparison | After training |
| `src/predict.py` | CLI inference — prints resistant cells, subclone table, 10-step drug sequence; same logic as app, no web UI | Terminal testing |
| `app/app.py` | 5-step Streamlit UI — degenerate-output detection (`probs.mean() > 0.85`), auto graph-building, dimension-adaptive projection, safe h5ad loader | Docker or `streamlit run app/app.py` |
| `notebooks/gdsc2-train-shesh.ipynb` | 31-cell Kaggle notebook — primary training path | Primary training |

## Training

### Option A — Kaggle (recommended, free T4 GPU)

1. Upload `notebooks/gdsc2-train-shesh.ipynb` to Kaggle
2. Add GSE220112 as a Kaggle dataset (uploaded as `mdirfanhossain212/gse220112`)
3. Run all 31 cells
4. Download `sc_rlot_outputs.zip` from the Output tab (Cell 30 creates it)
5. Extract into your local `models/` folder

### Option B — Local CPU

```bash
python src/train.py --config configs/config.yaml
# Override mode:
python src/train.py --config configs/config.yaml --mode local    # PBMC, fast epochs
python src/train.py --config configs/config.yaml --mode kaggle   # GSE220112, full epochs
```

### The 7-Step Pipeline (runs twice)

| Step | What Happens | Local epochs | Kaggle epochs |
|---|---|---|---|
| 1 | Load data — GSE220112 (kaggle) or PBMC 3k (local) | — | — |
| 2 | QC filter → log-normalise → top 500 HVGs | — | — |
| 3 | Subsample → PCA → UMAP → Leiden → k-NN graph | max 2,000 cells | max 15,000 cells |
| 4 | Train custom PyTorch VAE (500 genes → 32 latent dims) | 5→10 | 30→100 |
| 5 | Train GATv2 classifier (latent embeddings → resistance) | 10→15 | 25→80 |
| 6 | **Merge GDSC1 + GDSC2 → `data/gdsc_merged_ic50.csv`** | — | — |
| 7 | Train PPO agent via CancerDrugEnv | 500→1000 | 10k→50k steps |

**Run twice:**
- **Experiment 1** (baseline) → all files saved with `_exp1` suffix (e.g. `gat_model_exp1.pt`)
- **Experiment 2** (tuned) → files saved with **no suffix** (e.g. `gat_model.pt`) — these are the primary files used by `app.py`, `evaluate.py`, and `predict.py`

## config.yaml — Single Source of Truth

Every script opens `configs/config.yaml` with `yaml.safe_load()` at startup. **Nothing is hardcoded in any script.** Key values:

```yaml
model:
  n_latent: 32          # VAE output dimensions
  n_hidden: 128         # VAE hidden layer size
  gat_hidden_dim: 64    # GATv2 hidden dim per head
  gat_heads: 4          # GATv2 attention heads
  n_subclones: 9        # matches Kaggle Leiden clustering on 15k cells → OBS_DIM=9
  episode_length: 10    # RL treatment steps per episode
  ppo_timesteps: 50000  # Experiment 2 full training (kaggle mode)

subsample:
  max_cells_local:  2000
  max_cells_kaggle: 15000
  max_genes: 500

mlflow:
  experiment_name: "sc-rlot-cancer-drug-rl"
  run1_name: "experiment_1_baseline_20epochs"
  run2_name: "experiment_2_tuned_50epochs"
```

## CancerDrugEnv — RL Environment (rl_env.py)

```python
State:   Zero-padded subclone proportion vector, always OBS_DIM=9
Action:  Integer 0–4 (one of 5 AML drugs)
Reward:  (resistance_reduction × 10) − (toxicity_penalty × 0.5) − (tumour_burden × 0.5)
```

**Critical: `OBS_DIM = 9` fix.** The saved PPO model was trained on 15,000 Kaggle AML cells which produced 9 Leiden subclone clusters → observation shape `(9,)`. Any local dataset with fewer clusters would crash with:
```
Unexpected observation shape (4,) for Box environment, please use (9,) or (n_env, 9)
```
Fix: `_pad_obs()` always zero-pads the state to length 9 before returning from `reset()` and `step()`.

**Darwinian regrowth:** `regrowth = 0.03 × subclone_resist[resistant_subclone]` added to resistant subclone after each step — models clonal evolution.

**Toxicity array:** `[0.4, 0.3, 0.5, 0.35, 0.4]` for Venetoclax, Imatinib, Panobinostat, Dasatinib, Quizartinib respectively.

**Parameters:** dataset, n_cells, n_genes, n_subclones, vae_epochs, gat_epochs, ppo_steps, n_latent (32), gat_heads (4), k_neighbors (10), drugs, gdsc_sources, validation

## evaluate.py — Auto Model Selection

```bash
python src/evaluate.py
```

Searches for model files in this priority order:

1. `models/gat_model.pt` + `models/processed_adata.h5ad` — Kaggle/Exp2 output (preferred)
2. `models/gat_model_exp2.pt` + `models/processed_adata_exp2.h5ad`
3. `models/gat_model_exp1.pt` + `models/processed_adata_exp1.h5ad` — baseline fallback

Generates 3 artefacts saved to `artifacts/` and logged to MLflow:
- `confusion_matrix.png` — GATv2 classification accuracy
- `shap_gene_importance.png` — Top-20 resistance genes (red=known AML gene, blue=novel)
- `ppo_comparison.png` — PPO vs random reward bars per MLflow run

**SHAP known gene set** includes AML-relevant genes for all 5 drugs: BCL2/MCL1/BCL2L1 (Venetoclax pathway), FLT3/STAT5A/STAT5B (Quizartinib), HDAC1-3/EP300 (Panobinostat), ABL1/SRC/KIT (Imatinib/Dasatinib), plus TP53, RELA/NFKB1, CDK4/6, E2F1, and PBMC markers for local test runs.

## app.py — Streamlit App (5 Steps)

| Step | Function | Key Technical Detail |
|---|---|---|
| 1 | Load `.h5ad` or demo GDSC data | `load_adata_safe()` strips `uns/log1p` and `uns/neighbors` to handle anndata version mismatches |
| 2 | Treatment label distribution | DMSO vs Wee1i_AZD1775 bar chart from `adata.obs['treatment']` |
| 3 | GATv2 resistance classification | Degenerate-output detection: `probs.mean() > 0.85` → falls back to pre-computed `resistant` column |
| 4 | PPO 10-step treatment simulation | Dimension-adaptive projection: auto-adjusts `X_vae` dim to match saved model; plots resistance trajectory |
| 5 | SHAP gene importance | Loads `artifacts/shap_gene_importance.png` + `shap_gene_importance.csv`; run `evaluate.py` to generate |

**Drug descriptions shown in UI:**
- Venetoclax: BCL-2 inhibitor — blocks anti-apoptotic pathway (ABT-199)
- Imatinib: Kinase inhibitor — targets BCR-ABL, c-KIT, and PDGFR (Gleevec)
- Panobinostat: Pan-HDAC inhibitor — epigenetic reprogramming (LBH589)
- Dasatinib: Src/BCR-ABL inhibitor — dual kinase blockade (BMS-354825)
- Quizartinib: FLT3 inhibitor — targets FLT3-ITD/D835 mutations (AC220)

### Required Dockerfile lines

```dockerfile
COPY configs/               ./configs/

COPY models/                ./models/
COPY app/                   ./app/
COPY artifacts/             ./artifacts/
COPY mlruns/                ./mlruns/
COPY data/gdsc_merged_ic50.csv  ./data/
COPY data/processed_adata.h5ad  ./data/    # ← Critical — without this, 100% cells = resistant
```

### Docker errors and fixes

| Error | Cause | Fix |
|---|---|---|
| `No module named 'mlflow'` | Missing from `requirements_app.txt` | Add `mlflow==2.12.1`, rebuild with new tag |
| 15,000/15,000 cells resistant (100%) | `processed_adata.h5ad` missing from image | Add `COPY data/processed_adata.h5ad ./data/`, rebuild |
| `Could not load models` | `models/` folder empty | Copy Kaggle output files into `models/` |
| `Unexpected observation shape (4,)` | `OBS_DIM` mismatch in `rl_env.py` | Ensure `OBS_DIM = 9` in `rl_env.py` |
| `RunInfo missing run_uuid` | MLflow version mismatch | Use `mlflow==2.12.1` everywhere |
| `docker: image not found` | Running old tag after rebuild | Always use latest tag: `sc-rlot-app:1.2` |
